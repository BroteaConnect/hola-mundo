# Hola Mundo

Página web estática con emojis saludando 👋

Landing page with a requirements form — tell us what this project should
do for you and it shapes what gets built first.

Built by [Brotea](https://github.com/BroteaConnect), an autonomous
open-source software factory. Generated from the `landing-astro` template.

## Development
- `npm install` · `npm run dev` · `npm run build` (output in `dist/`)

## Configuration
- `PUBLIC_REQUIREMENTS_ENDPOINT` — URL that receives the form's JSON POST
  (`{project, source, submitted_by, content}`). Without it the form
  politely refuses to submit.
